# apps/mobile

This is the Expo / React Native shell. **Target device: Solana Seeker / Saga (Android).**

It is an M0 stub: a chat-first UI where every ask fails closed because there is no local model yet. Seed Vault and Mobile Wallet Adapter are not wired up yet.

```bash
npm install
npm run web      # run without a device
npm run android  # run on an emulator or a Seeker device
```
