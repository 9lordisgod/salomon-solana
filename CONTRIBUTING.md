# Contributing

This is a private, proprietary repository. Contributions are by invitation only.

- Branch from `main`, keep PRs small, and describe the change and how it was tested.
- Never commit secrets, keypairs, seed phrases, or `.env` files.
- Changes touching the on-chain boundary or sanitizer need a security review (see [SECURITY.md](SECURITY.md)).
- Docs use the goal tense for unshipped work. Do not claim a feature is live until it is verified.
