# Roadmap

- **M0: Scaffold.** Repo, docs, mobile shell stub, and boundary stubs.
- **M1: Local ask on Seeker.** Answer research prompts with an on-device SLM on Seeker, failing closed when no local model is available.
- **M2: Seed Vault boundary.** Connect through Mobile Wallet Adapter and Seed Vault, and prove that keys never reach the model.
- **M3: Propose-only transfers and signing.** Draft SOL/SPL transfers and message signs. Sanitize and simulate each one, then require explicit Seed Vault approval.
- **M4: dApp Store package.** Produce a signed release and submit it to the Solana dApp Store.
