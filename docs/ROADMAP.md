# Roadmap

> Planned sequence. Only **M0** is in progress (scaffold on `main`). **M1–M4 are not started** — no on-phone model, Seed Vault integration, chain actions, or dApp Store package has shipped.

- **M0: Scaffold (in progress).** Repo, docs, mobile shell stub, and boundary stubs.
- **M1: Local ask on Seeker (planned).** Aim: answer research prompts with an on-device SLM on Seeker, failing closed when no local model is available.
- **M2: Seed Vault boundary (planned).** Aim: connect through Mobile Wallet Adapter and Seed Vault, and prove that keys never reach the model.
- **M3: Propose-only transfers and signing (planned).** Aim: draft SOL/SPL transfers and message signs; sanitize and simulate each one; require explicit Seed Vault approval.
- **M4: dApp Store package (planned).** Aim: produce a signed release and submit it to the Solana dApp Store.
